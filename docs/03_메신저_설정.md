# 메신저 알림 설정

여러 채널을 동시에 쓸 수 있습니다. `config/config.yaml`의 `notify.channels`에서 쓰려는 채널을 `enabled: true`로 바꾸고, 비밀값은 `.env`에 적습니다.

| 채널 | 장점 | 한계 |
|---|---|---|
| **카카오톡 '나에게 보내기'** | 평소 쓰는 카톡으로 받음 | 메시지당 약 200자(자동 분할), **파일 첨부 불가**, 최초 인증 필요 |
| **텔레그램 봇** (추천 병행) | 설정 5분, **엑셀 파일 수신**, `/현황` 명령으로 실시간 조회 | 텔레그램 설치 필요 |
| 슬랙 / 디스코드 / 팀즈 | 팀 채널 공유 | 웹훅 주소 필요 |

추천 조합: **카카오톡(긴급 알림) + 텔레그램(현황 조회·엑셀 수신)**

알림 등급(`levels`)으로 채널별 받을 알림을 고를 수 있습니다:
`critical`(🚨 미출발·미도착), `warning`(⚠️ 지연확정·조기출발·미경유·위치미수신), `ok`(✅ 해소), `info`(ℹ️ 정상출발 등)

## 1. 카카오톡 '나에게 보내기'

### 1-1. 카카오 개발자 앱 만들기 (최초 1회, 약 10분)
1. https://developers.kakao.com 접속 → 카카오 계정 로그인 → **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름 예: `통근버스 알림`)
2. **앱 키**에서 **REST API 키**를 복사해 `.env`에 적습니다:
   ```
   KAKAO_REST_API_KEY=복사한키
   ```
3. **카카오 로그인 → 활성화 설정 ON**
4. **카카오 로그인 → Redirect URI**에 `http://localhost:8765/callback` 등록
5. **카카오 로그인 → 동의항목 → '카카오톡 메시지 전송(talk_message)'**을 '선택 동의'로 설정
6. (선택) **플랫폼 → Web → 사이트 도메인**에 `https://www.s1uvis.co.kr` 등록. 메시지의 'UVIS 열기' 버튼 링크용입니다.
7. (선택) **보안 → Client Secret**을 사용으로 설정했다면 `.env`에 `KAKAO_CLIENT_SECRET=값`도 적습니다.

> 카카오 개발자 콘솔의 메뉴 이름·위치는 바뀔 수 있습니다. 위치가 다르면 '카카오 로그인', '동의항목', 'Redirect URI'를 검색해 찾으세요.

### 1-2. 인증 (최초 1회)
`config.yaml`에서 kakao 채널을 `enabled: true`로 바꾼 뒤:
```bat
python -m uvis_monitor kakao-auth
```
브라우저가 열리면 카카오 로그인 → **동의하고 계속하기** → "카카오 인증 완료!"가 뜨면 끝납니다. 토큰은 `config\kakao_token.json`에 저장됩니다.
- 액세스 토큰(약 6시간)은 **자동 갱신**됩니다.
- 리프레시 토큰은 약 2개월 유효하며, 갱신할 때 만료 1개월 이내면 카카오가 자동 연장해 줍니다. 매일 실행하면 사실상 재인증이 필요 없습니다. 오래 쉬었다가 '토큰 갱신 실패' 로그가 나오면 `kakao-auth`를 다시 실행하세요.

### 1-3. 시험
```bat
python -m uvis_monitor test-notify
```
카카오톡 **'나와의 채팅'**에 시험 메시지가 오면 성공입니다.

## 2. 텔레그램 봇 (엑셀 파일·현황 조회)

1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 봇 이름 입력 → **토큰** 복사
2. `.env`에 적기:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ```
3. 텔레그램에서 방금 만든 봇을 검색해 **아무 메시지나 보내기** (예: 안녕)
4. chat_id 확인:
   ```bat
   python -m uvis_monitor telegram-chatid
   ```
   나온 숫자를 `.env`에 `TELEGRAM_CHAT_ID=숫자`로 적습니다.
5. `config.yaml`에서 telegram 채널을 `enabled: true`로 바꾸고 `test-notify`로 시험합니다.

**감시 중 쓸 수 있는 명령** (봇 채팅방에 입력, 본인 chat_id에서 온 명령만 처리):
| 명령 | 응답 |
|---|---|
| `/현황` (`/status`) | 전체 노선 실시간 현황판 |
| `/이상` | 이상이 있는 노선만 |
| `/보고서` (`/report`) | 현재까지 엑셀 보고서 파일 |

감시가 끝나면 일일 엑셀 보고서가 자동으로 전송됩니다.

## 3. 슬랙 / 디스코드 / 팀즈 (웹훅)

```yaml
    - type: webhook
      enabled: true
      format: slack        # slack / discord / teams / generic
      url: ${WEBHOOK_URL}
```
- **슬랙**: 앱 'Incoming Webhooks' → 채널 선택 → Webhook URL
- **디스코드**: 채널 설정 → 연동 → 웹후크 → URL 복사
- **팀즈**: 채널 → 워크플로 → '웹후크 요청이 수신되면 채널에 게시' → URL
